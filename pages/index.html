muir-sys

The Lisp Machine system for QUUX, the machine muir and muir-fpga evolve from the MIT CADR, continuing where System 100 left off, and evolved step by step.

System 1001 Release notes GitHub
What it is
  • The Lisp Machine system for QUUX, continuing where System 100 left off: MIT’s System 99.32, recovered from its backup tapes and brought up by LM-3.
  • QUUX is the CADR evolved, in muir and muir-fpga: better in performance and capacity — a bigger map, a 16K-word PDL buffer, multiply and divide in one instruction — and in modern computing, such as the display’s resolution, block storage and the network. It says which improvements it has, and the system reads them at boot.
  • It evolves the system, step by step, rather than changing it radically. Backward compatibility is not an aim, but System 1001 will always be supported by muir and muir-fpga.
  • System 1000 and System 1001 are out: each a disk pack ready to boot, and the sources. The release notes say what each changed; get them on GitHub. System 1001 is the last for the CADR, which stays on it; System 1002, the first for QUUX, is in progress.
  • It runs on muir, the software simulator, and muir-fpga, on an FPGA, with ozd as its Chaosnet services daemon.
  • The source is at github.com/metebalci/muir-sys, under the AGPL, version 3 or later.
